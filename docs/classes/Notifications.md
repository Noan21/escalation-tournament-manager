# Notification Routing

Typed models describing how notifications are configured, routed, and logged.

## 📫 Preferences

```python
from datetime import datetime
from typing import Literal, Optional
from uuid import UUID

from pydantic import BaseModel, EmailStr, Field, HttpUrl

ChannelType = Literal["email", "discord_webhook", "slack_webhook", "sms", "webhook"]
EventTrigger = Literal[
    "registration_confirmed",
    "round_pairings",
    "round_locked",
    "standings_published",
    "season_leaderboard",
]


class ChannelConfig(BaseModel):
    channel: ChannelType
    address: str = Field(..., description="Email address or webhook URL")
    enabled: bool = True
    rate_limit_per_hour: Optional[int] = Field(default=None, ge=1)

    @property
    def is_webhook(self) -> bool:
        return self.channel in {"discord_webhook", "slack_webhook", "webhook"}


class NotificationPreference(BaseModel):
    id: UUID
    organization_id: UUID
    subject_type: Literal["participant", "team", "admin"]
    subject_id: UUID
    triggers: list[EventTrigger] = Field(default_factory=list)
    channels: list[ChannelConfig] = Field(default_factory=list)
    muted_until: Optional[datetime] = None
    created_at: datetime
    updated_at: datetime

    def is_muted(self, now: datetime) -> bool:
        return self.muted_until is not None and self.muted_until > now
```

- Each preference ties to a subject (participant, team, or admin).
- `triggers` are the events where notifications should fire.

## 📨 Delivery Payloads

```python
class NotificationMessage(BaseModel):
    trigger: EventTrigger
    recipient_subject_type: Literal["participant", "team", "admin"]
    recipient_subject_id: UUID
    channel: ChannelType
    address: str
    subject: Optional[str] = None
    body_text: Optional[str] = None
    body_html: Optional[str] = None
    metadata: dict[str, object] = Field(default_factory=dict)
    created_at: datetime
```

- This is the canonical payload generated by `NotificationAgent` before handing off to delivery services.

## 🗒️ Delivery Log

```python
class NotificationDelivery(BaseModel):
    id: UUID
    message: NotificationMessage
    sent_at: Optional[datetime] = None
    status: Literal["queued", "sent", "failed"] = "queued"
    failure_reason: Optional[str] = None
    retry_count: int = 0
    last_attempt_at: Optional[datetime] = None
```

- Useful for audit trails and retry logic.

## ✅ Implementation Notes

1. Store preference models in `app/models/notification.py`.
2. Resolve actual addresses (`EmailStr`, webhook URL) from `ChannelConfig` before dispatching.
3. When integrating with Cloudflare Worker/webhook endpoints, map `NotificationMessage` to the worker payload directly.
